余りもの献立メーカー v0.28 — ホーム画面＆オフライン起動用（PWA）
=====================================================

これは「配布用の素材セット」です。ZIPをスマホにダウンロードしただけでは
PWAとしてインストールされません。最初にHTTPSのWebページで公開する必要があります。

【公開する側の手順（GitHub Pagesを例に）】
1. ZIPを展開して、index.html、sw.js、manifest.webmanifest、icons/ フォルダ、
   .nojekyll（空ファイル）を同じ階層に配置する。
2. GitHubの公開リポジトリを作り、上記のファイル／フォルダをアップロードする。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) を設定する。
4. 公開された https://＜ユーザー名＞.github.io/＜リポジトリ名＞/index.html にアクセスして
   アプリが表示されるか確認する（※ URLは公開後にGitHub上で確かめてください）。

【使う側の手順：Android Chrome】
1. 最初だけインターネット接続のある状態で上記HTTPSページをChromeで開く。
2. ページ表示後、Chromeの︙メニュー →「アプリをインストール」または
  「ホーム画面に追加」を選ぶ（表記や挙動は端末によって異なります）。
3. ホーム画面のアイコンから起動してみる。
4. 機内モードにしてアプリを完全に閉じ、もう一度ホーム画面から起動する。
   献立・レシピ・買い物リストを確認する。

【既存のローカルHTML版からデータを引き継ぐ】
* 旧HTML版で「レシピを見る」→「JSONバックアップ」を作成。
* 新PWA側で「レシピを登録」→ JSONバックアップを取り込む。
* 追加100品ファイルもPWA側へ取り込める。レシピの重複は読み飛ばす仕様。
* ローカルHTMLとPWAはブラウザ上で保存領域が異なるため、自動引き継ぎはできません。
* 取り込み後、追加レシピ数・写真・見た目設定が復元されていることを確認。

【オフラインと保存について】
* インストール・初回キャッシュ保存時はインターネット接続が必要です。
* 初回キャッシュ保存後、HTML・デザイン・基本27品のレシピはオフラインで開けます。
* 端末に追加したレシピと写真はブラウザの保存領域（localStorage）に入ります。
* 端末のサイトデータ消去、保存容量不足、公開URL変更などでデータが消える可能性があります。
  定期的なJSONバックアップ推奨。ブラウザアプリ自体を削除する前もバックアップ。
* レシピの外部URLリンク（YouTube等）はオンラインでのみ開けます。
* ZIPやローカルのindex.htmlを直接Chromeで開いても、PWAのインストール・
  オフライン起動キャッシュは有効になりません。必ずHTTPSで公開してください。
* 公開ページの配信と保存先を混同しないでください。レシピの手入力や画像データは
  サーバーへ送らず、その端末のブラウザに保存されます。

【更新時】
* 同じ公開URLのままで更新し、sw.js内のCACHE_NAMEを新しい版名へ変更すると
  新しいアプリ本体がキャッシュされます。URL変更は別アプリ扱いとなり得ます。

【公開前のチェック】
* HTTPSで開いた直後に、ネットワーク接続あり→機内モードでの再起動確認。
* Android Chromeで「ホーム画面に追加」または「アプリをインストール」が出るか確認。
* レシピ登録・100品一括読み込み・変更後の保存・バックアップ復元を確認。

注意：Android実機でのホーム画面へのインストール操作は未検証です。
このセットはHTTPSへ公開して初めてPWAとして使えます。
